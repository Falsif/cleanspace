# 💻 CleanSpace — умная очистка и анализ памяти компьютера

CleanSpace — настольная программа для Windows 10 и 11, которая помогает освободить место на дисках
и навести порядок: показывает, чем занят диск, находит временные файлы, большие и старые файлы,
дубликаты и разбирает папку «Загрузки». Интерфейс полностью на русском языке, тёмная и светлая тема
в стиле Windows 11.

**Главный принцип — безопасность.** CleanSpace ничего не удаляет и не перемещает без вашего явного
подтверждения, а перед подтверждением показывает точный список операций.

## Возможности

| Раздел | Что делает |
|---|---|
| **Главная** | Диски (объём, занято, свободно, % заполнения, кольцевые диаграммы), карточки итогов, кнопка «Начать сканирование». До проверки карточки показывают «Не проверено». |
| **Умная очистка** | Временные файлы пользователя (старше 1 дня), старый кэш приложений и шейдеров, кэш браузеров (Chrome, Edge, Яндекс, Brave, Opera, Vivaldi, Firefox), журналы ошибок и дампы, неиспользуемые временные данные, миниатюры Windows, корзина. У каждой категории — описание, количество, размер, уровень риска и галочка. |
| **Анализ дисков** | Дерево папок с размерами и долями, Treemap-карта диска, распределение по типам файлов (видео, изображения, музыка, документы, архивы, установщики, другое), открытие в Проводнике. Честно сообщает, если анализ неполный. |
| **Большие файлы** | Фильтры > 100 МБ, 500 МБ, 1 ГБ, 5 ГБ и свой размер. Открыть расположение, свойства, в исключения, в корзину. |
| **Дубликаты** | Группировка по размеру → быстрый хеш → полный SHA-256. Показываются только подтверждённо одинаковые файлы, предпросмотр картинок, ручной выбор, автовыбор только в личных папках. |
| **Старые файлы** | Старше 30/90/180 дней, года или свой период, с минимальным размером. |
| **Загрузки** | Состав папки по типам, старые установщики, архивы, повторно скачанные файлы («файл (1).zip»), сортировка по папкам с предварительным списком изменений, перемещение в выбранную папку. |
| **История очистки** | Журнал: дата, категория, обработано, освобождено, в корзину, ошибки с причинами. Отчёты за неделю и месяц, график по дням, экспорт в CSV. |
| **Настройки** | Тема, язык, безопасный режим, исключения, папки для анализа, уведомления и порог свободного места, фоновая проверка, экономичный режим, ограничение результатов, автозапуск, экспорт CSV, сброс. |

### Безопасность

- **Системные файлы Windows** (папка Windows, `pagefile.sys`, `hiberfil.sys`, точки восстановления,
  `System Volume Information`, драйверы) удалить из CleanSpace **нельзя** — эта защита не отключается.
- **Файлы программ** (Program Files, ProgramData, AppData\Local\Programs, `.dll`, `.sys`…) по умолчанию
  защищены. Разрешить действия с ними можно только в настройках, и даже тогда нужно отдельное
  подтверждение.
- **Личные файлы** (документы, фото, видео, загрузки, сохранения игр) никогда не попадают в «Умную
  очистку» и автоматически не выбираются. Их можно убрать только вручную и только **в корзину**.
- **Перепроверка перед действием:** файл должен существовать и не измениться с момента сканирования
  (размер и дата). У дубликатов дополнительно заново считается SHA-256, и проверяется, что
  оставляемая копия на месте и не изменилась.
- **В каждом наборе дубликатов всегда остаётся хотя бы одна копия** — и в интерфейсе, и в логике удаления.
- **Свежие временные файлы и кэш запущенного браузера не трогаются.** Если браузер открыт,
  категория его кэша блокируется с подсказкой «закройте браузер».
- **Корзина очищается официальной функцией Windows** (`SHEmptyRecycleBinW`).
- **Исключения нельзя обойти через символические ссылки и точки соединения:** CleanSpace вообще не
  переходит по ним при обходе и сравнивает реальные пути.
- **Честный учёт:** освобождённым считается только окончательно удалённое. Перемещение в корзину
  учитывается отдельно.
- Права администратора **не запрашиваются**, ничего не отправляется в интернет, нет рекламы,
  «чистки реестра» и «ускорителей Windows».
- **Безопасный режим** — только просмотр, все кнопки удаления и перемещения отключены.

### Производительность

- Все сканирования идут в фоне — окно не зависает; любую операцию можно остановить кнопкой
  «Остановить».
- **Экономичный режим** (включён по умолчанию) понижает приоритет процессора и диска на время
  сканирования и делает короткие паузы — ноутбук не тормозит.
- Списки ограничены самыми крупными N результатами (по умолчанию 5000), а дерево анализа хранит
  только нужное — расход памяти остаётся небольшим даже на дисках с миллионом файлов.
- Файлы без доступа пропускаются и подсчитываются, программа из-за них не падает.
- Файлы OneDrive «только в облаке» не читаются при поиске дубликатов (иначе Windows начала бы их скачивать).

## Быстрый старт

### Вариант 1. Готовый EXE (Python не нужен)
Скачайте `CleanSpace.exe` (см. «Сборка через GitHub» ниже) и запустите. Установка не требуется.

**Портативная версия:** распакуйте `CleanSpace_portable.zip`. Рядом с EXE лежит файл `portable.txt` —
благодаря ему настройки и история хранятся в папке `CleanSpaceData` рядом с программой (можно
носить на флешке). Без этого файла данные хранятся в `%APPDATA%\CleanSpace`.

### Вариант 2. Собрать EXE самому
1. Установите Python 3.10–3.13 с [python.org](https://www.python.org/downloads/) — при установке
   отметьте **«Add python.exe to PATH»**.
2. Дважды щёлкните `build.bat`. Скрипт создаст окружение, установит зависимости, прогонит тесты и
   соберёт программу.
3. Готовые файлы: `dist\CleanSpace.exe` и `dist\CleanSpace_portable.zip`.

### Вариант 3. Запуск из исходников
```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
Или просто запустите `run.bat`.

### Сборка через GitHub (без Python на компьютере)
В проекте есть `.github/workflows/build.yml`. Загрузите папку в репозиторий GitHub — сборка
запустится сама на сервере Windows. Готовый `CleanSpace.exe` появится во вкладке **Actions → последний
запуск → Artifacts → CleanSpace**. Если создать тег вида `v1.0.0`, файлы будут прикреплены к релизу.

## Тесты

```bat
pip install -r requirements-dev.txt
python -m pytest -q
```
Тесты создают искусственные файлы только во временных папках и проверяют: точность размеров,
русские имена и эмодзи в путях, исключения и защиту от обхода через ссылки, отмену, поиск реальных
дубликатов (в том числе файлов с одинаковым началом и концом, но разной серединой), правило «минимум
одна копия», перепроверку перед удалением, удаление только внутри разрешённых папок, защиту файлов
программ, перемещение без перезаписи, сохранение настроек и отчёты.

## Примечания

- Размеры показываются в двоичных единицах (1 КБ = 1024 байта), как в Проводнике Windows.
- При анализе целого диска часть места занимают области, недоступные без прав администратора
  (файл подкачки, теневые копии, служебные данные NTFS) — CleanSpace честно показывает, какой процент
  занятого места удалось учесть.
- Windows Defender иногда с подозрением относится к новым EXE, собранным PyInstaller. Сборка без
  UPX уменьшает такие срабатывания; если SmartScreen предупреждает — «Подробнее → Выполнить в любом случае».
