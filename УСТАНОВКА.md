# Установка CleanSpace — пошагово

## Способ А: собрать CleanSpace.exe на GitHub (Python на компьютере не нужен)

1. Зайдите на github.com → **New repository** → имя, например, `cleanspace` (можно Private) → **Create**.
2. На странице репозитория нажмите **uploading an existing file** и перетащите **всё содержимое**
   папки CleanSpace, включая скрытую папку `.github` (если браузер её не берёт — загрузите через
   GitHub Desktop или командой `git push`).
3. Откройте вкладку **Actions**. Сборка «Сборка CleanSpace.exe» запустится сама (≈5–8 минут).
   Если не запустилась — выберите её слева и нажмите **Run workflow**.
4. Когда появится зелёная галочка, откройте запуск → внизу **Artifacts** → **CleanSpace**.
   Скачается архив с `CleanSpace.exe` и `CleanSpace_portable.zip`.
5. Запустите `CleanSpace.exe`. Если Windows SmartScreen покажет «Система Windows защитила ваш
   компьютер» — нажмите **Подробнее → Выполнить в любом случае** (так бывает с любыми новыми
   программами без платной цифровой подписи).

## Способ Б: собрать на своём компьютере

1. Скачайте Python 3.12 с https://www.python.org/downloads/ и при установке обязательно отметьте
   **Add python.exe to PATH**.
2. Распакуйте папку CleanSpace, например, в `C:\CleanSpace`.
3. Дважды щёлкните **build.bat** и дождитесь надписи «Готово!» (первый раз — несколько минут,
   скачивается около 150 МБ библиотек).
4. Программа: `C:\CleanSpace\dist\CleanSpace.exe`. Её можно перенести куда угодно.

## Портативная версия

Распакуйте `CleanSpace_portable.zip` в любую папку или на флешку. Файл `portable.txt` рядом с EXE
включает портативный режим — настройки и история сохраняются в `CleanSpaceData` рядом с программой.

## Удаление программы

CleanSpace ничего не устанавливает в систему. Чтобы удалить:
1. В настройках выключите «Запускать вместе с Windows» (если включали).
2. Удалите `CleanSpace.exe` и папку `%APPDATA%\CleanSpace` (настройки и история).

## Требования

- Windows 10 или Windows 11, 64-бит.
- Около 80 МБ свободного места для EXE; 150–300 МБ оперативной памяти во время работы.
- Права администратора не нужны.
